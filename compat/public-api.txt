PACKAGE github.com/faustbrian/go-hedge
package hedge // import "github.com/faustbrian/go-hedge"

Package hedge executes explicitly replay-safe operations with bounded, delayed
concurrent attempts. It does not infer idempotency or clone request state; an
AttemptFactory must create independently owned mutable state for every attempt.

Construct a Policy with NewPolicy, then call Do for each logical operation.
The selected value belongs to the caller, even when returned with an error;
Report.Wait observes cleanup of all other returned values. Cancellation and
cleanup deadlines require cooperative caller-supplied callbacks. There are no
package-wide workers to shut down.

A compatibility Budget bounds additional attempts. Opt-in Resilience v1/v2
context scopes coordinate original and hedge admission across composed policies.
Endpoint diversity, replay safety, label privacy and aggregate cleanup limits
remain caller responsibilities. The package has no cgo bindings or required
external services.

CONSTANTS

const MaxBudgetCapacity uint = 1_000_000
    MaxBudgetCapacity prevents a nominally finite budget from acting as an
    operationally unbounded admission policy.

const MaxHedges uint = 64
    MaxHedges bounds policy allocation, retained failure metadata, and fan-out.

const MaxResourceLength = 128
    MaxResourceLength bounds resource and endpoint identities in bytes. It does
    not sanitize their contents or limit the number of distinct caller labels.


VARIABLES

var ErrInvalidBudget = errors.New("hedge: invalid budget")
    ErrInvalidBudget identifies a zero or otherwise unusable shared-work bound.

var ErrInvalidPolicy = errors.New("hedge: invalid policy")
    ErrInvalidPolicy identifies implicit, contradictory or unbounded policy
    configuration, missing Do inputs and invalid callback metadata/decisions.


TYPES

type Attempt[T any] func(context.Context) (T, error)
    Attempt performs one independently owned execution. Cancellation is
    cooperative; implementations must return promptly when ctx is canceled.
    Partial/zero values on failure are classified and, unless selected for
    return, disposed. Attempt panics become payload-free errors passed to the
    classifier.

type AttemptFactory[T any] interface {
	// NewAttempt runs synchronously with the logical/admission context, before
	// AttemptTimeout starts. It returns a non-nil unstarted attempt and an optional
	// endpoint of at most MaxResourceLength bytes. Construction failures/panics
	// always stop for the original, or follow FactoryFailureMode for hedges. Resources
	// not transferred in a started attempt remain the factory's responsibility.
	// Shared factories must support concurrent calls from separate executions.
	NewAttempt(context.Context, AttemptInfo) (Attempt[T], string, error)
}
    AttemptFactory creates independently owned mutable state for every attempt.
    Construction must honor the context, return promptly, and avoid starting
    the external operation. Endpoint must be a bounded, credential-free identity
    suitable for labels.

type AttemptFactoryFunc[T any] func(AttemptInfo) (Attempt[T], string, error)
    AttemptFactoryFunc adapts a non-blocking factory function. Use a concrete
    AttemptFactory when construction itself needs the logical context.

func (function AttemptFactoryFunc[T]) NewAttempt(_ context.Context, info AttemptInfo) (Attempt[T], string, error)
    NewAttempt invokes the adapted function without forwarding the context.
    A nil function panics; Do rejects typed nil factories before construction.

type AttemptInfo struct {
	// Ordinal is local to Do; denied or failed hedge slots can leave gaps.
	Ordinal uint
	// Hedge is false only for the original attempt.
	Hedge bool
	// Delay is the chosen delay for this slot, or zero for the original.
	Delay time.Duration
}
    AttemptInfo identifies an original or additional execution. Ordinal zero is
    always the original; positive ordinals are hedges.

type AttemptResult[T any] struct {
	// Value is the returned value, including partial/zero values on failure.
	// Classification does not transfer ownership or copy referenced state.
	Value T
	// Err is the attempt error, or a payload-free error for an attempt panic.
	Err error
	// ContextErr captures the attempt context error before classification.
	ContextErr error
	// Ordinal is zero for the original and the scheduling slot for a hedge.
	Ordinal uint
	// Hedge distinguishes additional attempts from the original.
	Hedge bool
}
    AttemptResult is passed to a Classifier. Value and Err are never included
    in observations or the package's wrapper error strings; unwrapped causes may
    retain the original error data.

type Budget interface {
	// Capacity returns the immutable positive bound, no greater than MaxBudgetCapacity.
	Capacity() uint
	// TryAcquire returns a non-nil permit and true on admission, or nil and false
	// on denial. Implementations must be safe for concurrent use.
	TryAcquire(resource string) (Permit, bool)
}
    Budget bounds shared additional work. Implementations may account globally,
    per resource, or over a documented recent-work window. Capacity must be
    immutable, finite, and consistent with non-blocking, panic-free TryAcquire.

type CanceledError struct {
	// Has unexported fields.
}
    CanceledError distinguishes caller cancellation from downstream failure.

func (err *CanceledError) Error() string
    Error returns a fixed caller-cancellation message.

func (err *CanceledError) Unwrap() error
    Unwrap returns the caller context error, including an expired caller
    deadline.

type Classification uint8
    Classification is the explicit policy decision for one completed attempt.

const (
	// ClassificationSuccess makes the result eligible for winner selection.
	ClassificationSuccess Classification = iota + 1
	// ClassificationFailure retains the failure and permits active or scheduled
	// attempts to continue.
	ClassificationFailure
	// ClassificationCanceled records a non-downstream cancellation and permits
	// other attempts to continue.
	ClassificationCanceled
	// ClassificationTerminal stops the logical operation without a winner.
	ClassificationTerminal
)
type Classifier[T any] interface {
	// Classify runs in the attempt worker, potentially concurrently with other
	// attempts and even after cancellation. It must finish cooperatively.
	// The decision is explicit: a non-nil attempt error does not automatically
	// prevent success. A returned error, invalid decision or panic is terminal.
	Classify(context.Context, AttemptResult[T]) (Classification, error)
}
    Classifier decides whether one result wins, fails, was canceled, or
    terminally stops the logical operation. It must be safe for concurrent use.

type ClassifyFunc[T any] func(context.Context, AttemptResult[T]) (Classification, error)
    ClassifyFunc adapts a function to Classifier.

func (function ClassifyFunc[T]) Classify(ctx context.Context, result AttemptResult[T]) (Classification, error)
    Classify invokes the adapted function. Direct invocation of a nil function
    panics; NewPolicy rejects typed nil classifier dependencies.

type CleanupError struct {
	// Failures counts disposer errors and recovered disposer panics.
	Failures uint
}
    CleanupError reports how many result disposals failed.

func (err *CleanupError) Error() string
    Error reports only the failure count, without disposer messages.

type Clock interface {
	// Now supplies comparable completion times and elapsed-time measurements.
	Now() time.Time
	// NewTimer starts a non-nil timer with a usable notification channel.
	NewTimer(time.Duration) Timer
	// WithTimeout returns a non-nil derived context and cancel function, preserving
	// parent cancellation/deadlines. Cleanup passes Background as the parent.
	WithTimeout(context.Context, time.Duration) (context.Context, context.CancelFunc)
}
    Clock supplies monotonic policy time, timers, and deadline contexts so
    scheduling can be tested deterministically. Implementations must be safe for
    concurrent use and must not panic.

type Config[T any] struct {
	// MaxHedges bounds additional scheduling slots, from one through MaxHedges.
	MaxHedges uint
	// ReplaySafe must be true: the caller explicitly permits concurrent replay.
	// The package cannot verify idempotency or clone request state.
	ReplaySafe bool
	// Delay is the positive repeated delay, or zero when another strategy is used.
	Delay time.Duration
	// Schedule contains exactly MaxHedges positive successive slot delays.
	// NewPolicy copies this slice; these are not offsets from the original start.
	Schedule []time.Duration
	// DynamicDelay chooses each positive slot delay instead of Delay or Schedule.
	DynamicDelay DelayFunc
	// TotalTimeout is a positive logical deadline. It does not forcibly interrupt
	// synchronous factories or other uncooperative caller callbacks.
	TotalTimeout time.Duration
	// AttemptTimeout is zero to use the logical context, or positive and at most
	// TotalTimeout. It begins after construction and covers the attempt/classifier.
	AttemptTimeout time.Duration
	// CleanupTimeout is a positive, separate cooperative deadline per disposal.
	CleanupTimeout time.Duration
	// Clock is the required shared time/deadline provider.
	Clock Clock
	// Budget owns additional admission unless UseResilienceBudget is true.
	Budget Budget
	// Classifier is the required explicit result decision policy.
	Classifier Classifier[T]
	// Disposer is required even when the value type has no resources to release.
	Disposer Disposer[T]
	// Observer optionally receives events; a typed nil observer is treated as absent.
	Observer Observer
	// Resource is a non-empty identity of at most MaxResourceLength bytes.
	// The caller must keep it credential-free and suitably low-cardinality.
	Resource string
	// FactoryFailureMode explicitly chooses stop or continue for hedge construction.
	FactoryFailureMode FactoryFailureMode
	// UseResilienceBudget requires exactly one v1 or v2 scope in the Do context
	// and an absent Budget. Shared scopes own original/hedge admission; an existing
	// physical attempt is borrowed and its permit remains owned by the outer layer.
	UseResilienceBudget bool
}
    Config defines every safety decision and dependency for a Policy. Exactly
    one of Delay, Schedule, or DynamicDelay must be configured.

type DeadlineError struct{}
    DeadlineError distinguishes the total policy deadline from downstream
    failure.

func (*DeadlineError) Error() string
    Error returns a fixed total-policy-deadline message.

func (*DeadlineError) Unwrap() error
    Unwrap returns context.DeadlineExceeded.

type DelayFunc func(DelayInput) (time.Duration, error)
    DelayFunc chooses a positive delay for the next scheduling slot.
    Denied admission and continued construction failure also advance slots.
    It runs synchronously, must return promptly, and must be safe for concurrent
    policies sharing it. An error, panic or non-positive duration stops the
    operation.

type DelayInput struct {
	// Hedge is the next scheduling slot in [1, Config.MaxHedges], not a start count.
	Hedge uint
	// Previous is the preceding chosen delay, or zero for the first hedge slot.
	Previous time.Duration
}
    DelayInput gives a dynamic delay policy bounded metadata. Dynamic functions
    must not retain hidden unbounded latency history.

type DisposeFunc[T any] func(context.Context, T) error
    DisposeFunc adapts a function to Disposer.

func (function DisposeFunc[T]) Dispose(ctx context.Context, value T) error
    Dispose invokes the adapted function. Direct invocation of a nil function
    panics; NewPolicy rejects typed nil disposer dependencies.

type Disposer[T any] interface {
	// Dispose handles values from successful, failed or panicking attempts,
	// including zero values. Each call has a fresh Background-derived cleanup
	// deadline, without caller context values. Errors/panics are counted by Wait.
	Dispose(context.Context, T) error
}
    Disposer releases resources owned by every non-selected returned value.
    It must be concurrency-safe and honor its cleanup context. Selected partial
    failure values, like selected successes, belong to the caller.

type ExecutionError struct {
	// Has unexported fields.
}
    ExecutionError reports failed execution, including local construction,
    delay/admission failure or terminal classification. Its message omits raw
    causes. On all-attempt failure the lowest ordinal supplies the cause;
    on terminal classification the selected completion does. Other paths use the
    local failure. Unwrap may expose caller/downstream error data.

func (err *ExecutionError) Error() string
    Error returns fixed text even for local failure paths; consult
    Report.Reason.

func (err *ExecutionError) Unwrap() error
    Unwrap returns the single selected/local cause, never a join of loser
    errors.

type FactoryFailureMode uint8
    FactoryFailureMode defines what happens when a hedge attempt cannot be
    constructed. Original-attempt factory failure always stops execution.

const (
	// FactoryFailureStop stops the logical operation and cancels active attempts.
	FactoryFailureStop FactoryFailureMode = iota + 1
	// FactoryFailureContinue records the failed hedge and permits later work.
	FactoryFailureContinue
)
type Failure struct {
	// Ordinal is the local original/hedge scheduling ordinal.
	Ordinal uint
	// Hedge identifies additional work, including continued factory failures.
	Hedge bool
	// Delay is the chosen slot delay, or zero for the original.
	Delay time.Duration
	// Duration covers attempt and classification; failed construction has zero duration.
	Duration time.Duration
	// Endpoint is the optional factory label, absent on construction failure.
	Endpoint string
	// Classification records the decision, which may be invalid on classifier failure.
	Classification Classification
}
    Failure retains bounded attempt metadata without retaining or joining raw
    error messages.

type Observation struct {
	// Outcome identifies the event; not every terminal failure has an event.
	Outcome Outcome
	// Ordinal is local to Do: zero is original, positive values are hedge slots.
	Ordinal uint
	// Delay is the chosen slot delay, or zero for the original.
	Delay time.Duration
	// Duration measures attempt plus classification time where available,
	// including on cleanup-failure events; it is not disposal latency.
	Duration time.Duration
	// Resource is the policy's caller-provided budget/observation identity.
	Resource string
	// Endpoint is the factory's optional caller-provided endpoint identity.
	Endpoint string
	// Classification is set for OutcomeAttemptCompleted and zero otherwise.
	Classification Classification
	// Winner marks the selected-success event, not every successful completion.
	Winner bool
	// Loser marks cleanup-failure events, not every non-selected completion.
	Loser bool
}
    Observation excludes returned values and raw errors. Resource and Endpoint
    are caller labels bounded in length, not automatically sanitized/redacted or
    cardinality-limited. Events from workers may arrive after Do returns.

type Observer interface {
	// TryObserve may run concurrently from coordination, attempt and cleanup
	// paths. Its result is ignored; delivery/storage policy belongs to the observer.
	// Panics are contained, but blocking can delay execution or cleanup.
	TryObserve(Observation) bool
}
    Observer receives bounded lifecycle metadata through a non-blocking method.
    TryObserve must return immediately and must not call back into an execution.

type Outcome uint8
    Outcome identifies one bounded lifecycle event. It is safe to use as a
    metric label after mapping unknown values to a bounded fallback.

const (
	// OutcomeNoHedgeNeeded records an original winner before any hedge started.
	OutcomeNoHedgeNeeded Outcome = iota + 1
	// OutcomeHedgeStarted records one admitted additional attempt.
	OutcomeHedgeStarted
	// OutcomeBudgetDenied records rejected additional work.
	OutcomeBudgetDenied
	// OutcomeWinnerSelected records a winner after additional work started.
	OutcomeWinnerSelected
	// OutcomeAllAttemptsFailed records deterministic failed-result selection.
	OutcomeAllAttemptsFailed
	// OutcomeCallerCanceled records caller cancellation.
	OutcomeCallerCanceled
	// OutcomeTotalDeadline records total timeout expiry.
	OutcomeTotalDeadline
	// OutcomeAttemptCompleted records one result published to the coordinator.
	OutcomeAttemptCompleted
	// OutcomeCleanupFailed records one disposer failure.
	OutcomeCleanupFailed
)
func (outcome Outcome) String() string
    String returns a bounded label; unknown values collapse to "unknown".

type OutstandingBudget struct {
	// Has unexported fields.
}
    OutstandingBudget bounds concurrent additional attempts across every policy
    and execution sharing the instance. Use one instance per resource when
    resources require independent limits; doing so avoids an unbounded hidden
    resource-key registry. Construct it with NewOutstandingBudget; nil and zero
    instances deny admission. Do not copy an instance after use. Permits release
    before disposal, so this is not a global bound on cleanup goroutines.

func NewOutstandingBudget(limit uint) (*OutstandingBudget, error)
    NewOutstandingBudget constructs a concurrency-safe budget with a limit from
    one through MaxBudgetCapacity. Invalid limits wrap ErrInvalidBudget.

func (budget *OutstandingBudget) Capacity() uint
    Capacity returns the immutable maximum number of outstanding hedges, or zero
    for a nil receiver.

func (budget *OutstandingBudget) Outstanding() uint64
    Outstanding returns a concurrent snapshot of currently admitted additional
    attempts, or zero for a nil receiver.

func (budget *OutstandingBudget) TryAcquire(_ string) (Permit, bool)
    TryAcquire reserves one additional attempt without blocking. A policy holds
    the permit until the completed result is consumed or reclaimed. Resource is
    accepted for the Budget contract but this implementation deliberately has a
    single bounded scope.

type Permit interface {
	// Release relinquishes admission when a result is consumed or reclaimed,
	// before its disposal. Admission therefore does not bound cleanup work.
	Release()
}
    Permit accounts for one additional attempt. Release must be idempotent,
    concurrency-safe, non-blocking, and must not panic.

type Policy[T any] struct {
	// Has unexported fields.
}
    Policy is immutable and safe for concurrent execution. Its Budget,
    Classifier, Disposer, Clock, and Observer dependencies must also be safe for
    concurrent use, as must shared DynamicDelay functions and attempt factories.
    The zero value is not an executable policy; use NewPolicy.

func NewPolicy[T any](config Config[T]) (*Policy[T], error)
    NewPolicy validates finite amplification, time, replay, ownership, and
    dependency contracts. It copies Schedule but retains collaborator/function
    references. Validation errors wrap ErrInvalidPolicy; no workers are started.

type RealClock struct{}
    RealClock uses the standard library's monotonic clock and timers. Its zero
    value is ready for concurrent use.

func (RealClock) NewTimer(delay time.Duration) Timer
    NewTimer starts a standard-library timer; non-positive delays fire
    immediately.

func (RealClock) Now() time.Time
    Now returns the current time.

func (RealClock) WithTimeout(parent context.Context, timeout time.Duration) (context.Context, context.CancelFunc)
    WithTimeout derives a standard-library timeout context. The caller must call
    the returned cancel function to release resources; parent must not be nil.

type Reason uint8
    Reason identifies the terminal logical outcome.

const (
	// ReasonNoHedgeNeeded means the original won before additional work started.
	ReasonNoHedgeNeeded Reason = iota + 1
	// ReasonWinnerSelected means one of multiple started attempts won.
	ReasonWinnerSelected
	// ReasonAllAttemptsFailed means every admitted attempt completed unsuccessfully.
	ReasonAllAttemptsFailed
	// ReasonCallerCanceled means the caller canceled the logical operation.
	ReasonCallerCanceled
	// ReasonTotalDeadline means the configured total timeout elapsed.
	ReasonTotalDeadline
	// ReasonTerminalFailure means classification stopped the logical operation.
	ReasonTerminalFailure
	// ReasonFactoryFailure means attempt construction stopped the operation.
	ReasonFactoryFailure
	// ReasonDelayFailure means dynamic delay selection failed validation.
	ReasonDelayFailure
	// ReasonBudgetFailure means shared budget setup or admission failed locally.
	ReasonBudgetFailure

type Report struct {
	// Reason describes the terminal logical outcome.
	Reason Reason
	// AttemptsStarted counts launched functions, excluding failed construction.
	AttemptsStarted uint
	// HedgesStarted counts launched additional functions, not scheduling slots.
	HedgesStarted uint
	// BudgetDenied counts hedge slots denied admission; each consumes a slot.
	BudgetDenied uint
	// WinnerOrdinal is meaningful for ReasonNoHedgeNeeded/ReasonWinnerSelected.
	WinnerOrdinal uint
	// SelectedOrdinal identifies the returned failure value on all-failed or
	// terminal-classification paths. Zero elsewhere is not evidence of selection.
	SelectedOrdinal uint
	// Failures is an ordinal-sorted snapshot of retained non-success metadata,
	// including continued construction failures. Later cleanup does not update it.
	// The caller owns the slice; Report copies share its backing array.
	Failures []Failure
	// Has unexported fields.
}
    Report describes one logical execution. Wait lets callers and graceful
    shutdown code wait for cooperative loser cleanup without delaying winner
    delivery.

func Do[T any](ctx context.Context, policy *Policy[T], factory AttemptFactory[T]) (T, Report, error)
    Do executes one original attempt and at most Config.MaxHedges additional
    delayed attempts, using a Policy constructed by NewPolicy. The factory
    supplies fresh mutable state; Do never clones/interprets requests.

    Among successes already published when selection closes, completion time
    wins and exact ties use the lowest local ordinal. No future completion can
    replace that selection. Terminal classification returns its partial value;
    all-attempt failure returns the lowest ordinal's value. Any selected
    returned value belongs to the caller, including on error; the package
    disposes other returned values.

    Do cancels other attempts cooperatively and returns without waiting for
    their cleanup; use Report.Wait during shutdown or when cleanup matters.
    Deadlines do not interrupt synchronous, uncooperative callbacks.
    Nil context/policy/factory yields ErrInvalidPolicy; caller cancellation
    and total timeout have distinct error types. Shared admission requires the
    configured Resilience scope version.

func (report Report) Wait(ctx context.Context) error
    Wait waits for accounted attempt/classification/observation work and
    disposal of every non-selected returned value. It is not a general goroutine
    join. Concurrent waits are supported. It reports disposer errors/panics by
    count, without their raw messages. A zero Report returns nil; otherwise
    ctx must be non-nil. Canceling ctx stops only this wait, not cleanup.
    Uncooperative attempts or callbacks can prevent completion.

type Timer interface {
	// C returns the timer notification channel; the execution receives but never closes it.
	C() <-chan time.Time
	// Stop releases timer resources without blocking or panicking and reports
	// whether it prevented the timer from firing.
	Stop() bool
}
    Timer is owned by one execution. Stop releases its resources; callers must
    not close C.
